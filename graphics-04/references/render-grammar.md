# 图面语法速查

对应代码：`scripts/svg_export.py` 里的 `FLOW_MEDIA`、`LAYER_ORDER` 以及三套面板布局函数。改代码时请同步本文件。

## 一、介质如何编码

只有三种介质，颜色和线型都在 `FLOW_MEDIA` 常量里：

| 键 | 图例文案 | 颜色 | 线型 | 例子 |
|-|-|-|-|-|
| material | 物料流 | `#1f5fa8` | 实线 | 培养基、料液、气体、废液 |
| energy | 能量流 | `#c1440e` | 虚线 `9,4` | 加热、电、蒸汽、能量输出 |
| information | 信息流 | `#2f7d4f` | 点划线 `2.5,3.5` | 信号、控制指令、数据 |

约定如下：

- 材料没说明介质时，按物料流画，并记一条 `medium_missing`；图例文案照常显示。
- 颜色只表示介质；方向类别另用线型表示。回流和逆向连接一律改成 `6,4` 虚线，同时改走下侧通道，不和正向连线抢位置。
- 图例只列当前图里出现的介质；`content_map.legend` 的 `in_svg` 字段给出它在 SVG 里的 id（`legend-line-<键>`）。

## 二、图元与 id 命名

- 圆角矩形：部件（`part-NN`）、步骤（`step-N`）、阶段（`stage-K`），`rx` 取 8 或 9。
- 深色小圆：图内序号徽标，id 为“主体 id + `-badge`”。
- 折线：连线（`conn-NN`）和阶段依赖（`dep-K`），必须带箭头 marker；线旁标签 id 为 `conn-NN-label`。
- 四点折线拼菱形：阶段里程碑，id 为 `stage-K-milestone`。
- 接口用部件左右两侧各一个 10×10 白色小方块表示，不单独给 id，归属部件层。

编号规则：部件和连线按材料清单顺序编号；步骤在图上永远重排成 1..N 连续号；阶段从 1 起编号，标题可带 workorder 里的阶段码。缺端点的连接保留 id 但不绘制（`drawable=false`），方便复核者追查它为什么没出现。

## 三、布局模板

**装置面板**——先把连接图做拓扑分层，层号小的一列放左边；同列往下排。箭头方向天然是从左列指向右列（或同列向下）。逆流/回流排到画布下方通道，每多一条通道面板加高 22。没有部件时只写一行缺口说明。

**流程面板**——单列从上到下，框高随标题行数变化；相邻步骤之间加竖直箭头。内容里的并行标志在框右侧标“并行支路”，回流目标标在框右上角。

**路线面板**——阶段卡片宽 262、间距 62，按画布宽度折成最多 4 列；每张卡片固定六段：目标、方法、输入、输出、依赖、里程碑。相邻阶段之间画推进箭头，跨阶段依赖用箭头旁文字标注，绝不指向图外。

**组合面板**——装置在上、流程/路线在下，共用一块画布，各自维护 y 游标；面板前缀 A/B/C 帮助对照。

## 四、文字尺寸与画布

字体按 Noto Sans CJK SC → Source Han Sans SC → Microsoft YaHei → SimHei → Arial → sans-serif 依次回退。字号分配：图题 22，面板题 17，部件名 13，正文 11–13，脚注/接口 9–10。折行按“CJK 一个全角宽、其他字符 0.55 个字号宽”估算，只折行不改字。画布宽度固定 1440，高度由所有图元的包围盒推出来，`overflow.ok` 负责兜底校验。
