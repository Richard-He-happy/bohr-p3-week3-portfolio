# 汇报组织规则：听众 → 时长 → 叙事 → 页 → 问答

本文件把 `SKILL.md` 第 5 节展开成可直接套用的判断规则。所有规则都服从同一个前提：页面上出现的每个断言，都能在源材料里指出具体位置。

## 1. 先定听众，再定背景厚度

| 听众/场合 | 背景页预算 | 方法讲到什么程度 | 结果怎么摆 | 结论口径 |
|-|-|-|-|-|
| 课题组组会 / 周会 | 0–1 页 | 机制、关键超参、失败点 | 进展与对比，未完成项要留位 | 保守，主动说风险 |
| 学位答辩 / 评审 | 1 页（为什么值得做） | 创新点 + 与已有工作的差异 | 主结果 + 消融 + 显著性 | 与证据等级严格一致 |
| 跨领域听众 | 2 页 | 只讲输入输出与直觉 | 一个最有说服力的数字 | 不外推，不夸大 |
| 合作方 / 工程落地 | 0 页 | 接口、成本、依赖 | 时延 / 资源 / 失败率 | 给出适用条件与不适用条件 |

术语只解释"这批听众可能不懂"的；同领域听众用行话反而更省时间。

## 2. 时长换算成页数，再换算成每页信息量

- 经验值：每页 1.2–1.5 分钟（含翻页与停顿）。12 分钟≈8 页，20 分钟≈13–15 页。
- 每页 3–5 条要点，每条中文 ≤25 字 / 英文 ≤14 词；装不下的细节写进 `notes`，不要塞进页面。
- 至少留 1–2 页备用页（补充数据、对照组、失败案例），由 `qa.backup` 指向。
- 题面给定的页数是硬约束，优先于上述估算：要求 8 页就交 8 页；内容不够就合并要点或加备用页，不许凑页。

## 3. 叙事骨架：按问题组织，不按论文段落组织

**通用主线**：问题（谁受影响）→ 现有做法为什么不够 → 我们的做法一句话 → 关键证据 2–3 页 → 边界与结论 → 下一步。

| 场合 | 骨架变体 |
|-|-|
| 组会进展 | 目标 → 本周做法 → 结果与阻塞 → 下周计划 → 需要什么帮助 |
| 答辩 | 问题价值 → 创新点（对比最近工作）→ 方法 → 主结果 + 消融 → 边界 → 贡献总结 |
| 评审 | 结论先行 → 证据链（每页一条证据）→ 证据强度与不确定性 → 建议 |

每页只回答一个问题，页标题就是该问题的答案（结论句式）。

## 4. 单页检查（写完逐页过一遍）

1. 页标题是不是结论？不是就改成"现象/数字 + 判断"。
2. 3–5 条要点是不是都支撑同一个 `claim`？有一条跑题就拆页或删掉。
3. 每条要点有 `locator`，`quote` 能逐字查到。
4. 数字与源材料一致（跨页同一数字口径统一），并写清样本量或实验条件。
5. `evidence_strength` 与证据匹配：单数据集 / 单模型 / 无对照 → `moderate` 以下。
6. `notes` 是否提供了页面之外的信息：讲法、适用条件、常见误解、被追问时的第一句回答。
7. 图表引用指向材料里真实存在的图号/表号；没有图就写"无（材料未提供）"，不要臆造图注。

## 5. 问答预案（每条都要能落到页）

| 追问类型 | 准备方式 | `backup` 指向 |
|-|-|-|
| 机制类（"为什么有效"） | 给机制链条，而不是再讲一遍结论 | 方法页或消融页 |
| 数据类（"样本量/划分/泄漏"） | 给数字与出处，说明划分方式 | 数据页 |
| 对照类（"和 X 方法比"） | 只给材料里有的对比；没有就直说"未做，属下一步" | 结果页或限制页 |
| 局限类（"什么时候失效"） | 主动给失效条件 | 限制页 |

至少 2 条、最多 6 条；答案与页面口径必须一致——同一数字在不同页出现两种说法，是最常见的扣分点。

## 6. 已知限制

- locator 的精度取决于源材料结构：PDF 依赖 `pdftotext` 的段落切分；扫描件（无文字层）只能登记为缺口。
- 不做图像内容的像素级读取：只做"引用绑定"（指向图号/表号/段落），不重绘图表数据。
- 模板继承保留母版、版式、主题与字体，但幻灯片是重建的：模板里的自定义占位符动画、SmartArt 不保证保留。
- 预览 PDF 的版式等价性依赖 LibreOffice；没有 LibreOffice 时是文本版预览，需要桌面端复核。
- 脚本不判断科学正确性，只保证"页面断言 ↔ 源材料位置"的对应关系成立；质量与科学性以人工评审为准。
