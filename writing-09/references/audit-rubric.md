<!--BEGIN:risks-->
# 风险清单与备选路径

## R1 源条件外推（第一阶段）
- 风险：材料给出的工艺条件与拟开展场景并非同一条件，外推可能不成立。
- 触发信号：重复实验相对偏差越过预注册阈值，或关键指标量级对不上。
- 备选：先退回同构条件建基线，再逐因素放宽，并改用替代指标。

## R2 指标达标（第二阶段）
- 风险：预设指标口径可能达不到。
- 触发信号：中期里程碑主要指标完成度不足计划六成。
- 备选：降级为趋势与效应量报告，同时追加一组对照。

## R3 结论稳健（第三阶段）
- 风险：样本量与重复次数不足，稳健性受限。
- 触发信号：留出集与训练条件之间指标差异越过容差。
- 备选：加独立重复批次，改留一条件交叉验证，如实披露不确定性。
<!--END:risks-->

## 一、每次运行都要复算的数

- 七节是否都写了实质正文：看 `sections_found`。
- 正文汉字总数是否落在 workorder 给的区间：看 `char_total`（只数表意文字）。
- 目标是否正好三个：看 `goals_count`。
- 时间标记最大月数是否越过周期上限：看 `max_month`。
- 规划单位分项之和是否等于 total 且不超上限：看 `planning_units_total`。
- 风险条数是否达到三条：看 `risks_count`；矩阵行数是否达到三行：看 `matrix_rows`。
- 人工确认是否达到两条且覆盖两类缺口：看 `pending_human_count`。
- 无据修饰计数：看 `banned_unverified`；边界表是否存在：看 `boundary_present`。
- 矩阵目标与单位分项目标能否 join：看 `matrix_units_joined`（自研断言）。

## 二、要么给来源、要么删掉的修饰

首次、国际领先、填补空白、重大突破、国内外首创、世界首创、尚无先例、领跑全球、开创性突破。
想保留就换成"已有研究显示（作者, 年）在 X 条件下达到 Y"，另起一句写"本申请拟把边界推进到 Z"。

## 三、写完每段后的四个追问

1. 结果是谁做出的？论文的 → 标"外部作者已完成"。
2. 计划句有没有"拟 / 计划 / 将"？没有就不能当已发生。
3. 这个条件是申请人自有的吗？没证据就写"待补（PH1/PH3）"。
4. 数字的 locator 找得到吗？找不到就降格"待核"并进 `pending_human`。

## 四、两个 JSON 的形状

`planning_units.json`：`cap`（上限）、`unit_meaning`（必须写非货币）、`items`（每项 `id`/`goal`/`units`）、`total`。
`pending_human.json`：数组，每项含 `id`、`topic`、`need`、`why`、`status`、`blocking`。

## 五、交付前的四步对照

1. 跑 `audit_kit.py --output <目录>`，critical 与 major 都必须归零。
2. 把矩阵三行手抄一遍，核对与正文编号同名。
3. 搜禁用修饰词、搜"万元/元"、搜"已具备"。
4. 打开 `result.json`：`workorder_execution` 的布尔量应全 true，`contract_keys_missing` 应为空。
