# 图面规范与导出设置（figure spec）

一句话：默认参数按"缩印到单栏仍可读、灰度打印不丢信息"来定；可用工单覆盖，但覆盖后必须仍然通过同一套机器检查。代码位置：`read_sources.STYLE`（样式字典）、`layout_studio.FONT_STACK / LAYER_ORDER`（字体栈与层序）、`export_drivers`（导出引擎链）。

## 画布与自适应

从 1200×760 像素起步，单位就是 px，`width/height` 与 `viewBox` 取同一个数，不写毫米。内容排不下时自动向下、向右扩，扩展后的实际尺寸记在 `compliance_checks.canvas`。安全性上限 4000×4000；超过就不只是"画得大"，而是排版出错，`canvas.ok` 会判假。间距约定：外边距 38 px，列与列之间 74 px，行与行之间 26 px——列距大于行距是刻意的，箭头需要落点。

工单里的 `canvas` 只当下限用：给的尺寸小会被放大，给的大也不会缩。要精确物理宽度，按 `mm = px / 300 × 25.4` 先换算再写进工单。

## 排版与可读性

字号只有四档：图题 11 pt（粗体，左下向上留白）、实体标签 8.5 pt（居中，超 22 字符按词折行、行高 1.5）、图例 7 pt（行距 19 px）、子图字母 11 pt 粗体。子图字母只在"示意图 + 数据面板"同时出现时加 A/B。6 pt 是硬地板：更小的字缩印后不可读，`style.ok` 直接失败。

线宽分四类：连接线 1.2 pt、实体框描边 1.2 pt、抑制端横杠 2.2 pt、刻度与辅助线 0.6 pt；整体允许区间 0.4–3 pt。实体框用 4 号圆角、填充 `#F2F7FB`、描边 `#0B5F8A`。

## 配色（每行一个语义，顺序无意义）

- 激活类：`activation #0072B2`
- 抑制类：`inhibition #D55E00`
- 结合类：`binding #009E73`
- 磷酸化：`phosphorylation #CC79A7`
- 表达类：`expression #56B4E9`
- 转化类：`conversion #E69F00`
- 包含类：`containment #8d979f`
- 因果及其它：`causal #333333`
- 数据系列循环取色（按系列出现次序）：`#0072B2`、`#E69F00`、`#009E73`、`#CC79A7`、`#D55E00`、`#56B4E9`、`#117733`、`#333333`

原则是"一个语义只住在一个颜色里"，并且颜色永不单独承载信息：必须同时有端点形状或图例文字兜底。

## 图例的机器约束

关系图例画线样、端点、类型名；数据图例画色块、系列名、单位。总数必须等于图面实际编码分类数，也就是关系类型数加数据系列数；`legend_consistency` 会算这个等式。图例框宽度随最长条目自适应，位置固定在内容下方，宽高写进模型。

## 可编辑性契约

SVG 骨架固定为：根节点带宽高与 `viewBox`；`<title>`/`<desc>` 说明图意；`<defs>` 里只放三种端点 marker；随后按 `background → panels → edges → entities → labels → legend → title` 顺序输出 `<g id="layer-…">`。所有文字是 `<text>`，不转曲、不嵌图、不引外部样式和字体。

id 是台账定位器：实体框 `ent-e1`、单行标签 `lbl-e1`、折行第二行 `lbl-e1-2`、连线 `edge-r1`、图例项 `lg-l1`、柱子 `bar-1-1`。`content_map.svg_ids_expected` 与它们逐字符对应。连线额外带 `data-rel-type`、`data-from`、`data-to`；实体框带 `data-entity-id`、`data-entity-type`，脚本改图时只认这些钩子。

编辑案例的约定：基线 id、图层名、坐标、样式全部保留，只替换工单点名的文字；`edit_record.json` 同时记录基线与修订后的 sha256，方便判断"是否只改了该改的"。

## 导出路线

优先级从矢量保真度与可获得性折中：先找 `rsvg-convert`，再 `cairosvg`，再 `inkscape`；都没有时先转 PDF 再 `pdftoppm` 光栅化（文字仍然清晰）；PDF 侧还可以走 LibreOffice Draw；最后才考虑 ImageMagick。PNG 目标为 RGB、白底、等价 300 dpi；PDF 目标单页、矢量优先。

一个引擎都没有时启用标准库兜底：zlib 手写 PNG（5×7 点阵字，只覆盖 ASCII），手写单页 PDF（base-14 Helvetica，只覆盖 Latin）。这两条兜底会在 `degradations` 里明确写出"文字覆盖受限"，不会假装完美。

每种格式实际用的引擎名要落在 `export_artifact.<fmt>.engine`；降级必须结构化记录，不允许静默换格式、也不允许把文本文件改名成 `.png`。

## 常见期刊参数速查

单栏图：宽 85 mm，字号 7–8 pt，线宽 0.5–1 pt；双栏图：宽 170 mm，字号 8–9 pt，线宽 0.75–1.2 pt，位图不低于 300 dpi；答辩或基金本子：宽 160–200 mm，字号 9–11 pt，线宽 1–1.5 pt，留白可以更宽松。

## 收工前看图的三问

1. 把图缩到 50% 还认得出箭头方向吗？
2. 转成灰度后，激活和抑制还能区分吗？
3. 只改一个标签，重新导出的图其它元素是否纹丝不动？三问都"是"才算可交付。
