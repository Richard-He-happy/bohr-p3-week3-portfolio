# 检索词映射表（中文问句 → 英文本体词）

本文件只服务于「找出该去哪些段落找证据」这一件事：每行把中文提问里的一个概念映射成
论文正文可能使用的英文词形。格式为 `- 中文 => 英文1 / 英文2 / …`，`#` 开头的行、
不含 `=>` 的行会被跳过。它不产出任何事实，映射不到时脚本按「材料未报告」处理。

维护提示：新增领域优先在此加行；同一中文键重复出现时后一行覆盖前一行。
